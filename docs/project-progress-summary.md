# 프로젝트 진행 요약

## 목표

PlayStation 일본판 Disc 1 《신세기 GPX 사이버 포뮬러 새로운 도전자》의
한국어 팬 패치를 재현 가능한 방식으로 제작한다. 원본 디스크 구조 조사,
역공학, 글꼴과 인코딩 해석, 대사 추출·번역·재삽입, raw Mode 2 디스크
빌드와 실행 검증을 하나의 파이프라인으로 연결한다.

현재 공개 배포판은 아니다. 그래픽을 제외하고 지금까지 식별한 폰트 문자열은
비배포 ROM에 정적 주입했으며, 번역 검토·특수 화면 실행 QA·베이크드 그래픽
문자 현지화가 남아 있다.

## 1. 원본과 개발 환경

- 지원 원본은 일본판 Disc 1 멀티 BIN/CUE로 고정했다.
- Track 1은 MODE2/2352, 602,020,272바이트이며 SHA-256은
  `35e43fba9c5ffc39ab805adbc42f13ec3198c888c1c1e9e651408409e041b2a9`다.
- 원본은 `roms/`, 추출·분석·빌드 파생물은 `work/`에 두고 Git에서
  제외한다.
- `create-retro-game-kr-patch`의 PS1 작업 방식을 프로젝트에 반영하고,
  `mini-yonku-wgp2-kr`의 재현 가능한 역공학·MCP 운영 방식을 PS-X EXE,
  MIPS R3000A, overlay와 raw CD sector 환경에 맞게 수정했다.
- IDA Pro/idalib은 명령 경계·xref·짧은 루틴을, Ghidra는 긴 제어 흐름과
  포인터 전달을 담당하게 해 상호 교차검증했다.
- DuckStation GUI와 Lua는 사용자 요청에 따라 자동 조작하지 않고 사람이
  직접 실행 검증한다.

## 2. 디스크 구조와 전량 추출

- `SLPS_019.58`의 파일 로더와 schedule을 분석했다.
- ISO 파일 16개, 파일 record 19개, descriptor 164개, scheduled 파일
  11개와 재결합 state 1,935개를 식별했다.
- `START.BIN`, `ALLBIN.BIN`, overlay, XA, VAB, CDDA, MDEC, 글꼴, 초상,
  그래픽 관련 자료를 추출·해제했다.
- 추출·재결합 결과, 크기와 해시를 검증해 원본 round-trip 기준선을 만들었다.
- 모든 최종 빌드는 이전 패치 ROM이 아니라 검증된 불변 원본에서 다시 만든다.

## 3. 글꼴과 인코딩

- primary 글꼴 1,229슬롯과 alternate 글꼴 1,484슬롯을 확인했다.
- 두 글꼴은 14×14 셀, 3bpp, 글리프당 74바이트 구조다.
- 수정된 primary/alternate 글리프 이미지를 기준으로 일본어 대응표를
  완성했고, primary 한자 배열이 JIS X 0208 계열 정렬을 따른다는 점을
  대조했다.
- 원본 글꼴은 6단계 명암 index와 CLUT를 사용해 흰 본문·회색 외곽선/그림자
  형태로 표시된다.
- 한국어 글꼴은 `galmuri11`을 확정했다. TTF 12px로 래스터화하면 실제 잉크는
  최대 약 11×11이며 14×14 셀 안에 들어간다.
- 영문, 숫자와 필요한 특수문자 보호 슬롯은 한글 배정에 사용하지 않는다.
- 별도 런타임 훅 없이 primary 글리프 index를 정적으로 재배정하고 대사
  u16 코드를 다시 인코딩하는 방식을 채택했다.
- 인코딩에 없는 문자가 하나라도 있으면 빌드를 실패시키도록 했다.

## 4. 대사 구조와 안전 공간

- `ALLBIN.BIN`의 직접 대사 5,783개를 안정 ID
  `disc1/allbin/u**/.../ref****`로 추출했다.
- 직접 포인터가 없는 연속 대사·선택 페이지 83개를 추가로 발견해 별도
  정본으로 관리한다.
- 화자, 초상, 음성, 페이지 대기, 종료와 기타 제어토큰을 대사와 분리해
  보존한다.
- 화면 기준은 한 줄 17글리프, 보통 3줄이며, 현재 편집 방침상 4줄을
  넘기지 않는다.
- 처음에는 각 대사를 원본 고정 슬롯에 맞추었으나, 대사 사이의 모든
  참조·제어 요소를 함께 재배치하면 unit 전체 원본 arena 용량 안에서
  대사별 남는 공간을 공유할 수 있음을 확인했다.
- `u00`과 `u21` 실험에서 모든 참조를 다시 연결하고 unit 총크기를 유지한
  결과, 분기·초상·화자명·음성·대사 진행이 정상 작동했다.
- 이후 `u00..u34`에 같은 정적 불변식을 적용했다. 사용자는 기존 통합판을
  제2장 종료까지 진행했고 해당 경로에서 프리즈, 초상·이름 유실과 분기
  밀림이 해결됐음을 확인했다.

## 5. 번역 자산과 편집기

- 원문, 완역 후보, 축약 후보, 글리프 코드와 제어토큰을 분리한 JSON 작업본을
  만들었다.
- 외부 AI 협업용으로 안정 ID, 일본어 원문, 최대 글리프와 번역 필드만 가진
  간결한 파일과 용어집 후보 파일을 만들었다.
- 번역 대사의 표기 충돌, 오인식, 줄 폭, unit 총용량과 제어토큰을 검사하는
  도구를 추가했다.
- 기존 네 workset 밖의 물리 gap을 재감사해 순차 이벤트·경기 색인·추가
  미니게임·저장 메시지 716개를 더 분리했다. 새 일본어 288종과 문맥 충돌
  14건을 수동 결정해 전체 한국어 초벌 번역을 만들었고, 716개 모두 원본
  레이아웃을 만족한다. unit 공용 arena와 `u38/u39` 전용 재패킹으로 정적
  주입했으며 독립 언어·런타임 검수는 남아 있다.
- Python/Tk 기반 통합 폰트 번역 편집기를 만들었다. 본편 대사, 무포인터
  페이지, 추가 순차·경기·저장 문자열, 미니게임, 코스 정보, 머신 설정, UI,
  고정 이름과 화자명을 총 7,014행으로 편집할 수 있다.
- 편집기는 원본 고정 안전 슬롯과 unit 공용 총용량을 별도로 표시하며,
  17글리프 초과, 총량 초과, 짧은 줄, 제어토큰과 찾기/일괄 바꾸기 필터를
  제공한다.
- macOS에서는 저장소의 `대사-편집기.command`로 실행할 수 있다.

## 6. 이름과 폰트 UI

- 주인공의 고정 한국어 이름을 성 `시바` 2글자, 이름 `세이치로` 4글자로
  확정했다.
- 주인공 이름 배열과 재표시 경로를 패치하고 화자명 34개를 용어집 표기로
  삽입했다.
- 이름 등록 화면의 폰트 UI 리터럴 4개를 번역했다.
- 일본어·영문·숫자·특수문자 입력 팔레트와 관련 런타임 버퍼는 보존했다.
- 머신명 `ブイハチ`는 `V8`로 통일하고 `브이하치`를 검색용 변형 표기로
  용어집에 남겼다.

## 7. 미니게임·코스·머신 설정

- 별도 소비자를 사용하는 `u38`과 `u43`을 IDA Pro와 Ghidra로 교차 조사했다.
- `u38`에서 미니게임 규칙·대사·결과 322개를 추출했다.
- `u43`에서 코스 설명 57개와 타이어·전략·윙·부스트 설정 설명 12개를
  추출했다.
- 총 391개 번역은 빈값, 보호 필드, 의미 기호, 레이아웃과 저장 슬롯 검사를
  통과했다.
- `{name:surname}`, `{name:given}`은 화면에서는 여러 글자로 펼쳐지지만
  저장 공간에서는 제어토큰 u16 하나를 소비한다. 이 차이를 반영해 과거
  4건의 거짓 슬롯 초과 판정을 수정했다.
- 특수 화면에 필요한 고유 문자 606개 중 576개는 기존 맵을 재사용했다.
  30개를 추가했으며 미매핑은 0개, 남은 primary 슬롯은 174개다.
- 그래픽 버튼과 이미지에 새겨진 `Machine Setting`, 타이어 라벨,
  `Course Information` 등은 폰트 문자열과 분리해 마지막 그래픽 단계로
  남겼다.

## 8. 현재 통합 빌드

2026-07-29 비배포 빌드는 다음을 한 이미지에 포함한다.

- `u00..u34` 직접·무포인터·추가 대사 6,482개
- 고정 주인공명과 화자명 34개
- 이름 등록 폰트 UI
- `u38/u43` 미니게임·코스·머신 설정 391개
- 추가 `u38` 미니게임 분기 73개와 `u39` 저장 메시지 27개
- 위 번역에 필요한 Galmuri11 primary 글꼴 맵

최종 Track 1:

```text
크기: 602,020,272바이트
SHA-256: 5c7ed4cc184b6f071a66ef05dead2c7e9258deda400cd430964d3f24cd11bf1c
```

정적 검증 결과:

- 원본 Track 1과 CUE 식별값 일치
- 일반 대사 5,783건 기계 배치 차단 0
- 특수 화면 391건 빈값·미매핑·고정 슬롯 초과 0
- `u00..u34` 35개 unit 공용 arena 총용량 초과 0
- 실제 변경 sector 475개와 Expected Write 집합 일치
- 변경 전후 Mode 2/Form 1 EDC와 zero-address P/Q ECC 유효
- 완성 Track에서 `START.BIN`, `ALLBIN.BIN`, `SLPS_019.58` 재추출 해시 일치
- Python 회귀 검사 176개 통과

이 BIN/CUE는 원본 데이터를 포함하므로 Git에 커밋하지 않는다.

## 9. 현재 판정과 다음 작업

2026-07-29 통합 비배포 ROM에는 현재 조사 분모의 그래픽 제외 폰트 렌더
번역 요소와 새로 확인한 716개가 모두 들어갔다. 정적 Expected Write,
Mode 2 EDC/ECC와 재추출 대조를 통과했지만, 색인·분기 전수 실행과 독립
언어 검수 전이므로 공개 패치 완성을 뜻하지 않는다.

다음 우선순위는 다음과 같다.

1. 새 716개의 경기·미니게임 색인 분기와 저장·불러오기 경로를 전수 실행한다.
2. 사용자가 미니게임 네 종류, 코스 정보, 동적 주인공명, 타이어·전략·윙·
   부스트 설정을 실제 화면에서 검증한다.
3. 남은 장과 분기 전체를 진행하며 크래시, 화자·초상·음성, 페이지 진행과
   번역 품질을 검수한다.
4. 통합 편집기에서 자연스러운 줄바꿈, 용어와 축약 대사를 계속 교정한다.
5. 마지막 단계에서 그래픽 에셋에 새겨진 문자를 화면→VRAM→RAM→저장 위치로
   연결하고 한국어 그래픽을 제작한다.
6. 전체 실행 QA가 끝난 뒤 원본 전체가 아닌 차분 패치를 생성하고 적용 결과가
   검증한 목표 이미지와 같은지 확인한다.

새 폰트 소비자나 누락 문자열이 실제 실행에서 발견되면 “그래픽 제외 폰트
문자열 완료” 판정을 다시 열고 동일한 추출·글꼴·슬롯·Expected Write
검증 절차에 추가한다.
