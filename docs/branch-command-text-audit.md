# 분기·커맨드 폰트 문자열 감사

## 목적

직접 대사 포인터 표만으로는 선택지, 확인 문구와 분기 직후 순차 페이지를
전부 찾을 수 없다. 2026-08-02에는 원본 `ALLBIN.BIN`의 기존 workset 밖
물리 gap을 다시 검색하고, 화자·음성 제어 셸, 종료 토큰, 인접 소비자와
IDA/Ghidra 정적 결과를 함께 대조했다.

## 이번에 확정한 누락

| 범위 | 수 | 판정과 처리 |
|---|---:|---|
| `u09 +0x5DF0` | 1 | 주크박스 `キャンセル`; 5글리프 고정 슬롯으로 별도 주입 |
| `u28 +0x0F72..+0x10C2` | 8 | 직접 참조 `FFFF` 페이지 뒤의 `8000` fall-through 분기 페이지; 추가 경기 workset으로 승격 |
| `u43 +0x3EA8..+0x4068` | 4 | 머신 설정 도입 순차 대사; 고정 제어 위치를 보존해 글리프만 교체 |
| `u43 +0x4444..+0x4784` | 16 | 설정 설명·저장 안내·확인 분기; `FFFD`, `D002` 주소 보존 |
| **합계** | **29** | 한국어 정본과 재삽입 경로 추가 |

`u43` 20개는 저장된 `FFFB` 개행 없이 런타임이 17열에서 자동 줄바꿈한다.
따라서 통합 편집기는 수동 개행을 금지하고 예상 1~4행을 자동 표시한다.
확인 선택의 두 항목은 한 슬롯 안에 있지만 원본 제어 워드의 토큰 인덱스와
바이트 주소를 바꾸지 않는다.

## 후속 확정

- `u30..u34 +0x7190..+0x7490`에는 `u19/ref0004..ref0017`에 대응하는 마지막
  장면 14페이지가 각 unit에 반복되어 총 70페이지 존재한다. 사용자 실행 화면과
  u30/u32/u34의 14개 시작 주소 참조를 확인해 runtime 소비 항목으로 승격했다.
  다섯 풀은 SHA-256까지 동일하며 정확한 페이지 경계로 추출·번역·재삽입한다.

## 계속 제외하는 후보
- `u24`의 한 후보는 주변 구조와 토큰 문법을 대조해 이진 데이터 오탐으로
  제외했다.
- `u39`의 저장·불러오기 27개 연속 메시지 표는 이미 별도 workset에 모두
  포함되어 있다. 이번 화면 누락은 그 표가 아니라 별도 고정/순차 소비자에서
  발생했다.

## 현재 분모와 검증 경계

- 특수 화면 workset: 418개 (`u38` 327, `u43` 91)
- 추가 순차·색인·저장 workset: 806개 (`u28` 9개, 최종전 미러 70개와
  짧은 경기 미러 6개 포함)
- 통합 폰트 편집기: 그래픽 에셋 제외 독립 번역 7,059행; 물리 미러는
  각 정본 행에서 자동 생성
- 빈 한국어, 미매핑 글리프, 고정 슬롯 초과: 0
- 신규 `u28` 8개와 `u43` 20개는 정적 제어·레이아웃 검증을 통과했지만,
  실제 모든 선택 분기의 PCSX-Redux 실행 검증은 남아 있다.

## 전체 선택 제어 재감사

`scripts/audit_branch_command_text.py`는 원본 `ALLBIN.BIN`에서 선택 시작에
쓰이는 `FFFD`와 분기 종료 `D002`·`D003`를 전부 열거하고, 다섯 정본
workset의 물리 범위를 뺀다. 2026-08-02 기준 결과는 다음과 같다.

| 제어 | 전체 | 정본 범위 안 | 범위 밖 |
|---|---:|---:|---:|
| `FFFD` | 480 | 371 | 109 |
| `D002` | 24 | 24 | 0 |
| `D003` | 185 | 185 | 0 |

범위 밖 `FFFD` 뒤에 유효한 primary 글리프가 2개 이상 연속되는 후보는
10개였다. `u09 +0x5DEA`의 `ⓧ　キャンセル`만 런타임 소비가 확인됐고,
나머지 9개는 좌표·패딩·미니게임 애니메이션·MIPS 인접 데이터 오탐이다.
원본의 `キャンセル` 리터럴도 전체 2회뿐이며, 하나는 기존 u12 대사,
나머지 하나가 이 u09 고정 슬롯이다. 따라서 현재 확인된 선택 분기
커맨드 누락은 `취소` 1건이고 새 미해결 커맨드는 0건이다.

감사 결과는 `work/analysis/disc1-branch-command-audit.json`으로 만들 수 있다.

```bash
.venv/bin/python scripts/audit_branch_command_text.py
```

앞으로 화면에서 일본어 커맨드를 발견하면 화면 위치만으로 기존 대사 ID에
끼워 넣지 않는다. 먼저 런타임 RAM 주소를 확보하고 원본 unit/오프셋으로
환산한 뒤, 직접 포인터·fall-through·고정 슬롯 중 어느 소비 방식인지 판정해
해당 workset과 고정 검증 수량을 함께 갱신한다.
